
# Development Notes

## Project Development

The project was prepared using C++.

### Implementation
The hash table uses the Mid-Square method to calculate bucket indexes.

### Collision Handling
Separate Chaining maintains multiple values in the same bucket.

### Compilation
The program was compiled using GCC with C++17.

### Verification
The program was executed successfully with 20 personalized student marks.

### Documentation
The repository includes the implementation, execution output, trace-match report, debugging report and video demonstration script.
